1
Set Up Your Accounts
All free to start. Takes 20 minutes.
GitHub — create a new repo
Go to github.com → New repository → name it "ai-receptionist" → Private → Create. This is where your code lives.
Vercel — connect your GitHub repo
Go to vercel.com → New Project → Import your "ai-receptionist" repo → Framework: Next.js → Deploy. Your app gets a free domain instantly.
Supabase — create project and run schema
Go to supabase.com → New Project → name it "ai-receptionist" → pick a password → Create. Then go to SQL Editor → paste the entire schema.sql file → Click Run. Your database is ready.
Anthropic — get your API key
Go to console.anthropic.com → API Keys → Create Key → Copy it. Add $10 credit to start. Claude Haiku costs ~$0.001 per conversation — $10 lasts thousands of calls.
Twilio — get a phone number
Go to twilio.com → Sign up free → Verify your number → Get a Trial Number (free, Canada number available). You get $15 free credit. A Canadian local number costs ~$1.50/mo after.
2
Deploy the Code
Upload all files to GitHub then set environment variables on Vercel.
Upload all project files to GitHub
Upload these folders and files to your GitHub repo in this structure:
ai-receptionist/ ├── app/ │ ├── api/ │ │ ├── chat/route.js │ │ ├── leads/route.js │ │ ├── twilio/voice/route.js │ │ └── twilio/respond/route.js │ └── dashboard/page.jsx ├── components/ │ └── ChatWidget.jsx ├── lib/ │ ├── supabase.js │ └── schema.sql ├── package.json └── .env.example
Add environment variables to Vercel
Go to Vercel → your project → Settings → Environment Variables → add each of these:
ANTHROPIC_API_KEY = sk-ant-xxxx NEXT_PUBLIC_SUPABASE_URL = https://xxxx.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY = eyxxxx SUPABASE_SERVICE_ROLE_KEY = eyxxxx TWILIO_ACCOUNT_SID = ACxxxx TWILIO_AUTH_TOKEN = xxxx TWILIO_PHONE_NUMBER = +12895550100
Get Supabase keys from: supabase.com → your project → Settings → API
Redeploy on Vercel
Go to Vercel → your project → Deployments → click the three dots on the latest deployment → Redeploy. Wait 60 seconds. Your app is live.
3
Connect Twilio Phone Calls
Takes 10 minutes. After this phone calls go to your AI.
Point your Twilio number to your app
Go to Twilio Console → Phone Numbers → your number → Voice Configuration → set "A call comes in" to Webhook and paste this URL:
https://your-app.vercel.app/api/twilio/voice?slug=hamilton-plumbing-pro
Replace "hamilton-plumbing-pro" with your client's business slug from the Supabase database.
Test with a real call
Call your Twilio number from your phone. The AI should answer within 2-3 seconds with the business greeting. Say "I have a leaking pipe" and watch it respond intelligently.
Twilio trial accounts can only call verified numbers. Verify your number first in Twilio → Verified Caller IDs.
4
Get Your First Paying Client
Do this BEFORE adding Stripe. Sell it manually first.
Add a demo business to Supabase
Go to Supabase → Table Editor → businesses → Insert Row. Fill in a fake plumbing business with real-sounding details. Then open the widget demo page and show it working during your sales call.
The 5-minute demo script
Call a local plumber and say: "I built an AI that answers your missed calls 24/7, books appointments, and sends you the lead details. Can I show you a 5-minute demo?" If yes — show them the chat widget live and play them a recording of a phone call. Close at $97/mo.
Onboard manually for first client
Add their business to Supabase by hand. Set up their Twilio number (forward their existing number or give them a new one). Embed the widget on their website. Done — collect $97 via e-transfer first month, then set up Stripe.
